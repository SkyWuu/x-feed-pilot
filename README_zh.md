# X Feed Pilot (XFP)

[English](README.md) | 简体中文

X Feed Pilot 是一款可以“操控“X推荐算法的工具。它能让你的“For You“ Timeline 遵循你指定的喜好标准推送内容。

## Why do you need it?

X 是最棒的信息源，它的推荐算法也很棒，就像 TikTok 一样，可以很好地识别用户的 pattern 并推送相关的内容，而且时效性很强，你能在第一时间刷到你感兴趣的内容。

但驾驭这个信息源常遇到以下问题：

1. **搜索不适合用于了解“话题/领域“：**首先，X的搜索功能众所周知的烂。其次，搜索更适合检索一些具体内容，但你无法通过搜索实现“看看最近开发者都用Jev做什么应用“，你只会搜到一些已经极其热门的帖子或二手屎，比如专门做 AI 媒体的账号分享的“JEV的 101 个应用“
2. **‘For You‘ Timeline 的效果受限于用户：**我用X的第一天起就希望在X上浏览更多英文区的内容，但我的 Timeline 始终会有一半的中推，因为作为一个中国人，会不自觉地在中文内容上停留更久。大部分人的**实际行为和理性大脑“想消费的内容“并不一致**，比如刷到黄推你无法忍住不看。久而久之，X 会持续给你推荐这些内容，尽管理智告诉你，你想在 X 上看到的内容不是这些。

而 X Feed Pilot 能让你可以自由地控制 X 推荐算法。比如它可以让你的 Timeline 减少中文 tweets 的推送、增加 new models 相关的 tweets 等等

## How does XFP work?

1. X Feed Pilot 会替代你在 X 上刷贴、搜索、点赞、停留等等，通过这些行为“告诉“X的推荐算法'Hey, pls push more contents like this'
2. 你只需要告诉 XFP 你希望在 Timeline 上看到什么内容
3. 不用害怕错失帖子，XFP 会把它看过的帖子都记录下来，并且标注它认为符合你要求的帖子，你可以在一个看板中查阅这些内容



## Run it locally

目前 XFP 是在 macOS 上运行的MVP级产品。它通过 Chrome 扩展操作已登录的 X 账号，由本地服务对有附图的主帖调用 Luna、无附图的帖子调用 Jev 完成决策判断，系统基于判断结果做出模仿真人的页面交互（跳过不看、仔细浏览、点赞等），并将阅读记录保存在本机。

### 准备

- macOS、Google Chrome、Node.js 20+、Python 3，以及可调用 Apple Vision 框架的 Clang
- TypeSafe 和 OpenAI API key
- 在浏览器登录 X 账号；建议使用单独的 X 账号做训练
- 在仓库中的 [PREFERENCE.md](PREFERENCE.md) 写入配置，系统会遵循其中的要求改造 X 推荐
- 配置 [search-seeds.json](search-seeds.json) ：在极端情况下，Timeline 里完全看不到符合 PREFERENCE.md 的内容，这时候要通过主动搜索一些关键词做冷启动。可以在 PREFERENCE.md 写完后让任何 agent 帮你配置 search-seeds.json

在项目根目录运行：

```sh
npm install
cp .env.example .env
# 在 .env 中填写 TYPESAFE_API_KEY 和 OPENAI_API_KEY
npm run build
npm start
```

开始会话前必须同时配置 `TYPESAFE_API_KEY` 和 `OPENAI_API_KEY`。也可以通过同名环境变量提供密钥；如果 `.env` 中有非空值，会优先使用它。本地服务监听 `127.0.0.1:47831`。

### 使用

1. 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，加载项目中的 `dist/extension/`。
2. 在 Chrome 中登录x账号并打开 `x.com`，点击扩展图标，再点击“开始会话”。
3. **保持 Chrome 窗口和训练标签页在前台。**切换到其他应用或标签页时，采集和会话计时会暂停；返回后自动继续。可以随时在扩展中停止会话。
4. 在登录另一个 X 账号的浏览器或 Chrome 配置文件中打开 [本地阅读页](http://127.0.0.1:47831/) 查看记录。查看时训练会暂停，返回训练页后继续。

每次会话最多运行 10 分钟、处理 80 条帖子，最多点赞 8 条、收藏 4 条。停止后再次开始会创建新会话；重启服务会结束尚未停止的会话。记录保存在已被 Git 忽略的 `data/pilot.sqlite`。

### 实现概览

- [Chrome 扩展](src/extension/)读取推荐流和搜索结果、执行浏览与互动，并在训练标签页失去焦点时暂停。
- [本地服务](src/server/)管理会话和操作上限。主帖有附图时调用 OpenAI 的 `gpt-6-luna` Decisions API，无附图时调用 Jev；两者都结合偏好、正文及按需访问的链接或账号页面判断。每次判断只请求一次，15 秒超时，不重试、不切换模型；连续三次模型判断失败后停止会话。广告标记的帖子会直接跳过。
- [阅读页](src/server/public/)展示保存在 SQLite 中的记录和判断结果。它使用 X 的嵌入组件展示原帖；嵌入失败时仍可查看本地文字快照。



### 参与开发

运行 `npm test` 会构建项目并执行自动化测试。修改扩展后，需要重新运行 `npm run build`、在 `chrome://extensions` 中重新加载扩展，并重启本地服务。涉及 X 页面交互的改动还需在已登录的 Chrome 中手工验证。提交 PR 时请说明行为变化和测试结果；修改弹窗或阅读页时请附截图。

### 已知限制

只处理主帖自身最多四张附图，引用帖图片和视频画面不参与判断。完整附图下载失败时，使用已有截图裁出对应图片的可见区域，并标注可能不完整；任一附图无法下载也无法裁取时，该帖记为“证据不足”并跳过互动。图片仅在本条帖子的判断与后续访问期间保存在内存，裁切临时文件会清理，不将图片写入数据库。无字幕视频仍可能缺少判断证据。本工具会自动操作 X 页面，包括点赞和收藏；这可能违反 X 的规则，并导致训练账号受限。
